# 🌐 คำสั่ง `web` - Mobile & PC Annotation Reviewer Tool

เครื่องมือ Web Application น้ำหนักเบาที่ออกแบบมาเพื่อการตรวจสอบ ยืนยัน และแก้ไข Bounding Box บนมือถือ Android (แนวนอน) และจอ PC อย่างลื่นไหล รันเป็น Local Web Server ให้เปิดใช้งานผ่านเบราว์เซอร์หรือวง LAN เดียวกันได้ทันที

---

## 🌟 ฟีเจอร์เด่น (Key Features)

### 1. 📱 ประสบการณ์ใช้งานบนมือถือ (Mobile Experience)
* **Responsive Landscape UI**: ออกแบบการจัดวางแบบแนวนอน (ซ้าย: แถบเครื่องมือ | กลาง: Canvas | ขวา: รายการ Labels | บน: แถบนำทางและปุ่มยืนยัน)
* **ปุ่ม ⛶ เต็มจอ (Fullscreen)**: ซ่อนแถบ URL และ Header ของเบราว์เซอร์มือถือ 100% ทำให้พื้นที่ทำงานกว้างเต็มตา
* **รองรับ Web App (PWA)**: สามารถกด "เพิ่มไปยังหน้าจอหลัก" (Add to Home screen) บน Chrome มือถือ เพื่อเปิดใช้งานเป็น Standalone App ไร้ขอบเบราว์เซอร์
* **Gesture Navigation**:
  * แตะ 1 นิ้วเพื่อเลือก ย้าย หรือดึงจุดจับ 8 จุดเพื่อปรับขนาดกรอบ Bbox
  * ใช้ **2 นิ้ว (Pinch-to-zoom)** เพื่อซูมเข้า/ออก และ **2 นิ้วลาก** เพื่อเลื่อนภาพ (Pan)
  * แตะพื้นที่ว่างแล้วลากเพื่อเลื่อนภาพ (Pan) ในโหมดสัมผัส
* **Tap-to-Change Label**: แตะเลือกกรอบบน Canvas แล้วแตะชื่อคลาสในรายการด้านขวาเพื่อเปลี่ยน Class ได้ทันที ไม่ต้องลากวาง
* **Tap-to-Create Bbox**: แตะเลือกคลาสในรายการด้านขวา แล้วแตะหรือลากบนพื้นที่ว่างของ Canvas เพื่อสร้างกรอบ Bbox ของคลาสนั้นทันที

### 2. 💻 ประสบการณ์ใช้งานบน PC (PC Desktop Controls)
* **Mouse Navigation ตามมาตรฐาน Annotation Tools**:
  * **ล้อเมาส์ (Scroll Wheel)**: หมุนเพื่อซูมเข้า/ออกโดยมีจุดศูนย์กลางตามเคอร์เซอร์เมาส์ทันที
  * **คลิกขวาค้างแล้วลาก (Right-Click Drag) หรือคลิกปุ่มกลาง (Middle-Click Drag)**: เลื่อนภาพ (Pan) ได้อิสระทุกโหมดโดยไม่ต้องสลับเครื่องมือ
  * **แผงควบคุมการซูมลอย (Floating Zoom Bar)**: ปุ่ม `+`, `−`, `Fit` (พอดีจอ), `1:1` (ขนาดจริง 100%) พร้อมแสดงเปอร์เซ็นต์ซูมเรียลไทม์
  * **Cursor Interactive Feedback**: เคอร์เซอร์เปลี่ยนรูปตามจุดจับอัตโนมัติ (`nwse`, `nesw`, `ns`, `ew`, `move`, `crosshair`)
* **คีย์ลัดบน PC (Keyboard Shortcuts)**:
  * `Space` หรือ `Enter`: ยืนยันรูปปัจจุบันและข้ามไปรูปถัดไปทันที
  * `A` หรือ `←`: ไปยังรูปก่อนหน้า
  * `D` หรือ `→`: ไปยังรูปถัดไป
  * `Delete` หรือ `Backspace`: ลบกรอบ Bbox ที่เลือก
  * `Ctrl + Z`: ย้อนกลับ (Undo) การกระทำล่าสุด
  * `1` / `2` / `3`: สลับโหมด Select / Draw / Pan
  * `+` / `−`: ซูมเข้า / ซูมออก
  * `F`: ปรับขนาดภาพให้พอดีหน้าจอ (Fit to screen)
  * `0`: รีเซ็ตการซูมเป็นขนาดจริง (100%)

### 3. 🎨 การจัดการ Class และบันทึกข้อมูล
* **Custom Class Colors**: คลิกที่จุดสี หรือแตะแช่ที่แถบคลาส (หรือคลิกขวา) เพื่อเปิด Color Picker กำหนดสีของแต่ละ Label ได้ตามต้องการ
* **Sort Options**: สลับการเรียงลำดับรายการ Label ด้านขวาได้ทั้งแบบตามข้อมูลดั้งเดิม หรือเรียงตามตัวอักษร A-Z
* **Real-time Auto-save & Status Tracking**: ทุกการแก้ไข/เปลี่ยนคลาส/สร้างกรอบ จะถูกบันทึกลงไฟล์ JSON ของ X-AnyLabeling ทันที และเมื่อกดปุ่ม **"✓ ยืนยัน & ถัดไป"** ระบบจะเพิ่มสถานะ `"checked": true` ลงใน JSON ให้อัตโนมัติ

## 💻 ตัวอย่างการใช้งาน

### 1. กรณีแยกโฟลเดอร์รูปภาพและ Label JSON
```powershell
python main.py web --images raw_datasets/images --labels raw_datasets/labels --classes classes.txt --port 8000
```

### 2. กรณีที่รูปภาพและ JSON รวมอยู่ในโฟลเดอร์เดียวกัน
```powershell
python main.py web --images my_dataset/ --classes classes.txt --port 8000
```

### 3. เปิดใช้งานผ่านวง LAN เพื่อเข้าจากมือถือ
รันคำสั่งด้านบน แล้วเปิดเบราว์เซอร์บนมือถือที่เชื่อมต่อ Wi-Fi วงเดียวกัน ไปที่:
```text
http://<IP-ของเครื่อง-PC>:8000
```

## 📋 พารามิเตอร์ทั้งหมด

| Flag | รูปแบบ | ค่าเริ่มต้น | คำอธิบาย |
|---|---|---|---|
| `--images`, `-i` | Path | *จำเป็น* | พาธโฟลเดอร์รูปภาพ |
| `--labels`, `-l` | Path | `None` | พาธโฟลเดอร์ Label JSON (หากไม่ระบุจะค้นหาในโฟลเดอร์เดียวกับภาพ) |
| `--classes`, `-c` | Path | `None` | ไฟล์ `classes.txt` สำหรับกำหนดรายการคลาส |
| `--host` | String | `0.0.0.0` | IP Address สำหรับรันเซิร์ฟเวอร์ (`0.0.0.0` รองรับการเปิดจากเครื่องอื่นใน LAN) |
| `--port`, `-p` | Int | `8000` | Port สำหรับรัน Web Server |
